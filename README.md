# Projetos em Python – Matheus Maurilio
 
Este repositório contém alguns projetos simples que desenvolvi para praticar Python.
 
## 🐍 Projetos
 
### 📌 Calculadora Simples
Arquivo: `calculadora.py`  
Programa que realiza operações matemáticas básicas: soma, subtração, multiplicação e divisão.
 
### 👶 Classificação de Idade
Arquivo: `idade.py`  
Pergunta a idade do usuário e diz se é criança, adolescente, adulto ou idoso.
 
### 📋 Cadastro de Usuários
Arquivo: `cadastro.py`  
Cadastra nome, idade e email de usuários e salva em arquivo `.txt`.  
Também permite listar todos os usuários cadastrados.
 
### 🎯 Jogo de Adivinhação
Arquivo: `adivinhacao.py`  
Gera um número aleatório de 1 a 10 e desafia o usuário a adivinhar.  
Mostra se o palpite é maior ou menor que o número sorteado e conta as tentativas.
