## Python

### Calculadora
Calculadora em terminal com adição, subtração, multiplicação e divisão, incluindo validação de entrada e divisão por zero.

### Cadastro de usuários
Exemplo de CRUD introdutório em terminal. Permite cadastrar e listar usuários usando persistência em arquivo texto.

### Classificação de idade
Programa simples para praticar entrada de dados, conversão de tipos e estruturas condicionais.

## Desenvolvimento Web

### Odontologia Fortes
Protótipo de site institucional responsivo para uma clínica odontológica de Campo Grande — MS.

O HTML/CSS está em `web/odontologia-fortes/index.html`. Os arquivos de mídia usados pelo protótipo não estão versionados neste repositório, então algumas imagens/vídeos não serão exibidos ao abrir somente o HTML.

## Como executar os projetos Python

É necessário ter Python 3 instalado.

```bash
git clone https://github.com/matheusmaurilio001/projetos-python.git
cd projetos-python
python python/calculadora.py
```

Troque o nome do arquivo para executar os outros exemplos.
