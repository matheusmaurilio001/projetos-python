# Odontologia Fortes

Protótipo de site institucional desenvolvido em HTML e CSS para a Odontologia Fortes, em Campo Grande — MS.

## Estado do projeto

O arquivo principal está em `index.html`.

O protótipo referencia imagens e um vídeo dentro de uma pasta `imagens/`, mas esses arquivos de mídia não estão presentes neste repositório. Por isso, o projeto foi preservado como código de estudo/portfólio e não deve ser tratado como uma versão pronta para produção.

## Recursos implementados

- layout responsivo;
- menu de navegação;
- apresentação de procedimentos;
- seção da equipe;
- galeria;
- mapa incorporado;
- botões de contato por WhatsApp;
- chamada para agendamento.
